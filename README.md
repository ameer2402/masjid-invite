# 🕌 Masjid-Al-Akbari — Grand Opening Invite Page

A beautiful, animated invitation page for the grand opening of **Masjid-Al-Akbari** (مسجد الاکبری) in **Vangoor**.

## ✨ Features

- **Animated Preloader** — Islamic-themed loading screen with Bismillah
- **Floating Lanterns** — SVG lanterns with glow effects swinging from the top
- **Particle System** — Canvas-based golden & green particles rising across the page
- **Scroll Reveal Animations** — Elements animate in as you scroll (slide, scale, fade)
- **Live Countdown Timer** — Counts down to Sunday 15/11/2026 at 1:30 PM
- **Geometric Patterns** — Rotating Islamic geometric patterns as background decoration
- **Shimmer Gold Text** — Animated gradient text for headings
- **Click Ripple Effects** — Golden ripples on every click
- **Mouse Parallax** — Geometric patterns respond to mouse movement in the hero
- **Sparkle Dots** — Floating sparkle particles across the viewport
- **Glowing Borders** — Animated border glow on cards and frames
- **Responsive Design** — Looks great on desktop, tablet, and mobile

## 🚀 How to Open

Simply open `index.html` in any modern web browser:

```bash
open index.html
```

Or use a local server:

```bash
# Python
python3 -m http.server 8000

# Then visit http://localhost:8000
```

## 🛠 Tech Stack

- Pure **HTML5**, **CSS3**, **JavaScript** (no frameworks)
- Canvas API for particle system
- Intersection Observer API for scroll reveals
- Google Fonts (Amiri, Playfair Display, Poppins, Great Vibes)
